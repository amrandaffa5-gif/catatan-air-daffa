# catatan-air-daffa
Catatan Air Daffa adalah web app mobile-first bergaya Anime &amp; Glassmorphism untuk digitalisasi pencatatan meteran air. Aplikasi serverless ini menghitung tagihan otomatis, menyimpan data aman di HP (LocalStorage), dan membuat rekap laporan WhatsApp dalam 1 klik. Praktis, estetik, dan ringan!
